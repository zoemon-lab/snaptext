SnapText（Windows 版）
======================

画面の一部を囲むと、写っている文字を読み取って自動でコピーするアプリです。
縦書き・横書きの日本語と英語に対応しています。画像も文字も PC の外には送りません。

必要なもの：Windows 10 / 11（64 ビット）


■ はじめて開くとき
------------------------------
1. ダウンロードした zip を右クリック →「すべて展開」
2. 中の SnapText.exe を、好きな場所（例：ドキュメント）に置いてダブルクリック
   ・インストールは不要です。管理者権限もいりません
   ・「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
     （有料の電子署名をしていないため、この確認が出ます）
   ・はじめの起動は少し時間がかかります


■ 使い方
------------------------------
・Ctrl + Shift + 9 → 画面が暗くなるので、読みたい部分をドラッグで囲む（Esc でやめる）
  → 文字が出て、すでにコピーされています（Ctrl + V で貼り付け）
・画像ファイルを窓にドラッグ、または窓で Ctrl + V（Windows + Shift + S で撮ったスクショなど）
・「改行をとる」で、改行を除いた文章にしてコピーし直せます
・「×」で閉じても、画面右下（通知領域）に残ります。アイコンのメニューから終了できます
・アイコンのメニューの「Windows の起動時に自動で起動」で、毎回開く手間がなくなります


■ 縦書きについて
------------------------------
・縦書きらしいときは、自動で縦書き用の読み取りに切り替わります
・判定をまちがえたときは、窓の「縦書きとして読み直す」「横書きとして読み直す」を押してください
・縦書きと横書きが混ざった範囲は、分けて囲んでください


■ うまくいかないとき
------------------------------
・「日本語の文字認識が入っていません」
  → 設定 → 時刻と言語 → 言語と地域 → 日本語の「…」→ 言語のオプション →「光学式文字認識」を追加
・「縦書きを読むには Visual C++ 再頒布可能パッケージが必要です」
  → Microsoft の「Visual C++ 再頒布可能パッケージ（x64）」を入れてください（横書きはそのまま読めます）
・「Ctrl+Shift+9 はほかのアプリが使っています」
  → 窓のボタンか、右下のアイコンのメニューから読んでください
